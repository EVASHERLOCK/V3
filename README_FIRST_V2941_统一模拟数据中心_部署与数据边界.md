# Pharma Procurement AI V2.9.41 — 统一模拟数据中心和全关联种子库

## 本次交付是什么
- 在 V2.9.39 的基础上添加「统一模拟数据中心」，导航位于原「主数据中心」下方。保留原主数据页面，避免破坏历史入口。
- 生成明确标注 **SIMULATED / 模拟数据** 的制药采购种子库：80 供应商、120 物料、24 项目、30 产品线、四种 Kraljic 品类、2025-11 至 2026-10 的 12 个月业务记录。
- 其中 PO、询价报价、合同、QC、库存、生产、发票、付款、指标事件均为 1,440 条。每笔记录可基于供应商、物料、项目、PO 等键关联，额外包含变更、索赔、风险事件。
- 网站在 SIMULATED 模式下使用同一套种子 CSV，为采购执行九页生成数据；可以按供应商、物料、项目和月份过滤。

## 如何启动
```bash
npm install
npm run build
npm run dev
```
`npm run build` 和 `npm run dev` 会用纯 Node.js 解压 `seed_archive/*.csv.gz`，产生本地 `seed_simulated/*.csv`；不需要 Python，不需要事先在 GitHub 上传多 MB CSV 文本。构建同时生成静态发布所需的 `dist/` 内容。

访问左侧 **主数据中心 → 统一模拟数据中心**，或哈希路由 `#sim-center`。

如需原 V2.9.39 DEMO 行为，可执行 `npm run dev:legacy`（仅建议单独的测试环境）。

## 管理数据
只读查看/下载不需要凭证。新建、修改、删除及 CSV 导入必须在持续运行的 Node 环境使用：
```bash
SOURCING_ADMIN_TOKEN='请使用足够长的随机密钥' npm run dev
```
在统一模拟数据中心管理区输入令牌；系统向 `/api/sim-data/*` 提交经过认证的请求。主键被别的表引用时，拒绝直接删除。CSV 修改写回服务端的 `seed_simulated/*.csv`。

**关键限制：** 修改 CSV 只更新 Node 运行时 CSV，不自动更新已经生成的 SQLite、构建发布文件或 12 个月 KPI 快照；重新构建/重算和重发版后才会同步相关静态资产。静态 `bolt.host` 发布模式的数据中心只能只读；真实在线写入需要持久化 Node 后端/数据库，Bolt 静态发布本身不能提供持久 CRUD。不得把管理员令牌写进公开源码或前端常量。

```bash
npm run check:simulated

npm test                   # 原站回归测试
```
报告：`seed_simulated/SITE_DATA_AUDIT_V2941.json`，月度汇总：`seed_simulated/monthly_kpi_summary.csv`，SQLite：`seed_simulated/pharma_seed_simulated.sqlite`。

## 必须了解的验收边界
- 通过：种子 CSV **记录字段非空**；SQLite 外键、关联主键、付款/发票金额核验；连续 12 个月；九个采购执行页面数据层；主站构建与历史回归。
- **未通过“全站所有页面无待接入”的验收。** 旧版绩效中心 115 个 KPI 当前只有 15 项具备已实现的计算映射，仍有 100 项未接通新模拟指标事件。多个历史模块保留独立的 DEMO 数据引擎，不能声称每个组件都已统一到这一套种子库。
- 对不具备完整业务事件/审核口径的 KPI，必须继续显示缺失或数据来源不足；不能将模拟值包装成真实企业值。
- 线上 Bolt/浏览器的端到端全页逐图核查**尚未完成**；本次检查为源码、自动化脚本、数据审计与接口检查。
- 本数据只用于产品原型演示和测试，不是制药 GxP 验证数据，不用于财务结算、法规申报或实际供应商绩效评价。
