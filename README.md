1. 解压 `Pharma_Procurement_AI_Bolt_V08_COMPLETE.zip`。

## 发布机制

- `npm run build` 自动生成 `dist/index.html`、`dist/static/`、`dist/engine/`、`dist/samples/`。
- **公开发布的默认 KPI、统一风险、文档与业务看板在访问者浏览器中计算**，无 Render 免费 Python 服务休眠问题。
- `npm run dev` 运行 Node 本地服务；CSV/XLSX/PDF 解析能力取决于本地 Node 依赖；正式静态发布支持 CSV 重新计算，**尚不支持公开端 XLSX/PDF 内容理解**。
- 当前原版 `m03` 的供应商寻源分析和旧版 KPI CSV 上传分析均保留（通过原页面或 Legacy Tab）。

## 核心指标口径

- Spend = Σ `ordered_qty × unit_price`，模拟币种 `DEMO-USD`。
- Supplier OTD = 供应商承诺日或之前收货的有效 PO 行 / 有实际收货日与承诺日的有效 PO 行；不等同生产齐套率。
- Production Material Readiness = 在工单需求日已获得授权放行且库存分配充足的生产需求行 / 可关联生产需求行。跨 QA/Planning/Procurement，不归责于采购个人。
- PPV = Σ `(PO unit_price - benchmark_price) × ordered_qty` / Σ `benchmark_price × ordered_qty`。正数表示高于基准的价格差异，不是自动确认的业务损失。
- Savings 已实现值仅来自 **明确标识的模拟财务确认账** `v08_demo.json`，不等同价格低于基准或潜在机会。
- 库存金额以关联采购单价估算，**不能代替企业财务实际库存估值**。
- 长期 12 月/12 周趋势均带“模拟历史”标签，不能被当作旧 PO 数据构成的同比。

## 数据安全与模拟边界

- V0.8 是公开演示网页，所有数据都是编造的；请勿上传公司内部受限采购/质量/MA 文件。
- 浏览器 localStorage 的任务、告警、复审、订阅、角色日志不是服务器存储，不跨设备同步、不防篡改。
- “打印 PDF”是浏览器打印为 PDF；Excel 兼容导出采用 CSV；审计 ZIP 为**文档索引**，不包含虚构的 GMP 原件。
- 法规事件是示例情景，不是被实时证实的 FDA/EMA/NMPA 更新。
- 正式电子签名、QA 批次放行、ASL 批准、供应商锁单、付款执行、自动推送邮件均未开启。
- 真正部署企业系统，需要独立的 API 服务、身份认证、数据库、受控 DMS、外部供应商搜索连接、合规数据规则更新与数据验证。
