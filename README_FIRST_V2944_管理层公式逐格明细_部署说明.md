# Pharma Procurement AI V2.9.44 — 管理层计算与分析解读

这是对 V2.9.43 的 **模块级证据展示层** 的更新，不重写原业务模块。全站原有右上角「∑ 本模块公式 / 分析依据」、下方「▤ 展开全量计算依据和来源表」和 Excel 下载入口仍保留。

## 本次改变

- 右上角：优先显示该组件识别出的每一项 KPI 的变量、公式、分子分母、来源行数；逐字段/业务缩写术语解释；逐步的分析与文字结论。没有匹配的指标不得伪造公式。
- 左下角：优先显示页面当前模块的来源表，表内计算单元格以 `F4: =IF(...)` 方式展示公式和当前结果；显示列合计、可复算服务端源行、文字分析和管理结论。
- 旧的 `PARTIAL_EVIDENCE`、`SOURCE_ONLY_RECOMPUTED` 等来源审计不再占据主要界面，而收纳于「技术核验附录」折叠区。**并未修改来源等级的判定规则**。
- Excel：保留原有真公式工作簿，增加「管理层逐步文字解析」「变量术语解释」「逐格公式索引」「管理层结论与条件」「原文逐段解释」五张工作表；源展示表仍为真正 Excel 公式单元格。
- Node Preview 和 bolt.host 静态发布备用接口都采用上述结构。无线上 Node 后端时静态来源仍只具备模拟能力，筛选后的真实业务重算需要 Node。

## 数据口径与边界

本页面计算表来自当前模块的可见行；单元格坐标对应同一次导出的「模块表1、模块表2…」，第 4 行起为来源记录。对页面无表格/无已绑定指标的模块不会自动拼接无关 PO/QMS 数据。**输入单元格是来源值，不应被伪装为计算公式。** 只在数量×单价、得分×权重、实际−基准等可以从字段含义判断的场合创建逐行公式。所有来源依然是 SIMULATED，不能当作正式 GMP / QA / RA 审批证据。

## Bolt 更新与验证

解压完整 ZIP 后覆盖项目文件，确保 `executive_module_v2944.mjs` 等新文件在仓库根目录。重新 `npm run build && npm run dev`，在 Preview 中展开一个有 PO 明细的卡片：能看到单元格公式、当前行计算值、步骤与术语；下载 Excel 比对「模块表1」对应单元格。再 Publish → Update 发布 bolt.host，分别检查 Preview 与发布站。

目前没有直接登录你的 Bolt 项目执行线上端到端验收；构建和本地公式核验不代表真实环境全部已通过。
