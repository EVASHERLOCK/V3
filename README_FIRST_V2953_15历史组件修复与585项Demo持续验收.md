目前 **585 项完整 Demo 业务验收通过仍为 0 项**。每项的全部来源主键、筛选条件、网页全部数值与下载 XLSX 全部单元格独立同值、全部文字结论逐条核验都没有完整证据。17 项 API 返回的来源键为“接口返回样本”，不等于核验 23 份文件中与组件匹配的全部原始行。

有些 ss-data 模块当前只有“未配置 / 只读预览”，工作簿中的少量 COUNTIF 等真实公式不能代表有相应真实业务计算。应该保留“当前无数据 / 不适用”，不可把公式存在或按钮可下载直接当作业务核算通过。

## 执行命令

```bash
npm run build
npm run check:v2952:source
npm run check:v2953:retest
npm run check:v2953:demo
npm run check:v2953:demo:strict  # 证据未全时按设计返回非0
```

需要 Python Playwright、可运行 Chromium 和 Node.js >=20。当前 Chromium 原生 HTTP 页面导航受环境策略禁止，测试将网站打包脚本加载进 Chromium，通过 Python 代理向实际运行的 Node Demo API 发起请求。**这不是浏览器原生 HTTP 端到端测试**。
