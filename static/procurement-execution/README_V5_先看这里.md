# 全球药企采购执行 V5｜九页面紧凑复核版

此项目由 V4 原型直接修改，没有重新建立采购数据，也未改动 V4 的 `assets/data.js`、`assets/biz_data.js` 或原有 65 份 Excel 工作簿的字节内容。

## 如何打开

解压 ZIP 后，在文件夹中双击 `index.html`，自动跳转 `00_询价与报价比对.html`；顶部导航可切换全部 9 个子页面。建议使用新版 Chrome 或 Edge。所有业务数据均为合成演示，未连接正式 SAP / ERP / QMS / AP。

## V5 修改记录（逐条对应本次要求）

1. **九页共用**：`Word / PDF / Excel / EDI 单据接收 · 新旧版本比对` 改为 `details/summary` 折叠区，默认收起。
2. **九页共用**：`新版提取字段与完整原文 · 可人工修改和复核`、`字段差异结果` 改为折叠区，默认收起，点标题展开；人工修改和字段复核功能保留。
3. **九页共用**：在“载入可直接体验的双版本示例”按钮上方增加文档定位筛选器，选项与该页“需要提取 / 复核的全部字段”**同源且一一对应**。选择某字段会自动打开文档接收区、定位并高亮新版和旧版匹配段落；如果没有可信文本或没有找到字段，明确显示缺失说明。
4. **九页共用**：旧版红色标删改、新版绿色标新增；发生差异的行保留黄色底色，当前定位段增加蓝色焦点边框，方便看原文。
5. **02 PO 至 08 跨流程异常中心**：把原有 `逐笔业务记录与字段比对` 从后部移动到 KPI 下方的 **02 区**，将其余模块顺次后移。
6. **01 合同至 08 异常中心**：第 02 区主明细表保留原有全部字段和原有记录，**默认仅显示前 5 条**，点击“展开剩余”可以查看其余记录，点击“收起”恢复五条。说明：这是收起**记录行**，绝不是删除字段列。
7. **九页共用**：凡“逐笔业务记录与字段比对/合同字段对比”均增加蓝、绿、紫、橙的列头分区、隔行底色、悬停高亮等 UI 效果；原始字段文字、数据、来源及公式未改。
8. **九页共用**：`单据复核及七步异常闭环` 调整到 `月度绩效趋势与指标联动` 上方。七步内容和异常记录不删除、不改业务口径。
9. **00 RFQ**：`RFQ 报价可比性矩阵` 同时展示 6 个 RFQ 的折叠标题，但**仅第 1 个 RFQ 的明细表默认展开**，其他需要手动展开，不跨 RFQ 混比、不改原有红黄绿评审状态和 17 列字段。
10. **全量计算与血缘保留**：所有页 `∑` 分析规则、`?` 变量说明、Excel 下载以及全量来源表仍可使用。源数据及工作簿 V4→V5 二进制字节校验不变。

## 使用提示

- 进入任意页面，找到“业务清单 / 版本与字段比对”，点击“单据接收”标题展开。
- 从定位筛选器挑选字段：如“账期”“报价版本”，两侧阅读器自动滚到对应候选条款。演示文档为独立合成内容，不写回 KPI/Excel，也不代表正式合同审查。
- 点击“新版提取字段与完整原文”可查看编辑栏；点击“字段差异结果”可查看逐字段差异表。
- 在第 02 区查看前五条交易；点击“展开剩余 N 条”可以查看全部底表记录，Excel 仍然保存所有数据。
- RFQ 只开放第一个 RFQ，其他 RFQ 点击标题展开。

## 部署与技术边界

- 静态离线网页中，DOCX/XLSX/基础 EDI 的浏览器读取能力属于演示解析；复杂扫描 PDF 必须接入可信 PDF/OCR 服务。
- 目前的红绿差异是可审核的文本差异，不是具备法律效力的 AI 判断。
- 不能据前端的“QA/RA/来源符合”演示标签直接执行正式批准或 ERP 下单。
- 在原型中浏览器可以本地保存部分复核选择，但 GxP 电子记录、审计追踪、版本权限和电子签名需要正式后端建设。

## 验证范围

九页 JS 语法检查、静态结构与 DEMO 字段定位已通过 Node 环境校验；原始数据源及 65 份工作簿与 V4 完全一致。浏览器自动化访问当前环境受限，未宣称通过 Chrome/Edge 的完整端到端人工操作测试。建议开发团队按 `验收_V5_逐项核对.md` 在目标浏览器中完成 UI / 上传 / 滚动 / 导出复测。
