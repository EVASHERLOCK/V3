# 药企采购执行 V4 · 九页面逐项改版

**打开方法**：解压完整 ZIP 后，打开 `index.html`，默认进入 `00_询价与报价比对.html`。导航保留九个页面（00–08）。所有记录均为合成 DEMO，不代表实际 ERP/SAP、质量、RA 或银行系统数据。

## 这次统一应用到九个页面的变更

1. **字段清单独立占据完整一行**：`需要提取 / 复核的全部字段` 位于独立整行；左侧复选框、右侧完整文本阅读器。默认勾选两个字段供直接体验；点击任何复选框，立即展示对应字段完整原文。上传可提取文本后优先展示文件匹配原文及来源位置；无可靠匹配时，标示 `DEMO 示范文本`，不伪装成自动抽取成果。
2. **新旧文件分别有阅读区**：在 `上传新版文件` 按钮下方显示新版，在 `上传旧版文件` 下方显示旧版。`Word .docx` 提取正文段落；`.txt` / `.csv` / `.json` / `.edi` 读取文本；`.xlsx` 在浏览器读取主要工作表 XML 并显示单元格内容；PDF 和图片可看原件。**旧版红色删除、新版绿色新增、差异段落黄色底纹**。文字差异采用可复验的本地算法，不是已连接真实 AI 语义审查。扫描 PDF/图片的 OCR、PDF 文本定位和复杂格式比对仍需后端服务。
3. **七步异常闭环**：`单据复核及七步异常闭环` 已在所有页面移动到 `量化诊断、规则预警与行动建议` 后面；七步骤骤内容与已有异常记录展示逻辑保留。
4. **全量来源表直接显示**：非 RFQ 页原 `逐笔业务记录与字段比对` 中的精简明细已替换成原隐藏区的**完整来源字段表**，默认直接展示完整演示记录及所有原始和派生列，保留逐笔血缘、异常入口和模块 Excel 下载。RFQ 按单独指令移除该重复页内模块。
5. **对比位置**：非 RFQ 页先出现来源字段表，再在分析区域出现 `可见的自动核对结果`；RFQ 的报价自动比对和总成本计算器都放在分析与规则预警区域后部。
6. **全量公式追溯不删除**：每个模块的 `∑ 计算血缘 / 分析规则`、右上角 `?` 变量字典和左下角独立 Excel 工作簿保持可用；`workbooks/` 保留 V3 全部计算工作簿并新增补充工作簿。

## RFQ · 询价与报价比对（00）

- 报价矩阵按照 **RFQ ID / 物料 / 使用工厂 / 适用市场** 分组，每组单独排序，保留候选绿、待复核黄、阻塞红。
- 17 列：询价单 RFQ、供应商报价 ID、供应商、物料、需求数量、最小订单量 MOQ、报价原币单价、报价币种、单位需求到岸成本、预算金额、报价交期、技术资料符合、质量符合、RA符合、来源/市场实施就绪、评审结论、操作。
- `预算金额` 在原始底表没有，**显式显示“尚未接入预算”**，不得用报价金额冒充预算。单位需求到岸金额沿用 V3 当前有据可算的费项（货值、运费、税、冷链）；代理、保险、境内运输是否包括应在总成本计算器进一步复核。
- 删除 RFQ 的 `逐笔业务记录与字段比对` 重复模块，保留独立可复算 RFQ 矩阵工作簿 `workbooks/00_rfq_matrix_v4.xlsx`。
- 在 KPI 卡片（含 `MOQ 超需金额敞口`）之后增设六步骤流程图，六项详细文案与用户要求逐项一致。
- `采购总成本计算器` 和 `可见的自动核对结果 · 不同供应商报价比对` 位于量化诊断/预警/行动建议后部，后面才是七步异常闭环。

## 合同 · 核查与条款比对（01）

- 将合同逐笔业务记录从原第 06 区调整为 **第 02 区「合同字段对比」**。
- 17 列：合同编号、合同类型、关联 PO、供应商、物料、总金额/币种/单价、账期、清关/关税/保险、规格书/质量附件版本、违约与赔偿/责任上限、Incoterms + 指定地点、服务及质量验收、合同到期日、NDA 保密期限/允许用途、风险类别、条款异常标志、操作。
