# 药企采购执行 V6｜九页面局部布局修订

在 V5 的九页面代码基础上修改，**仅变更页面显示/折叠行为**；沿用原业务数据、九个业务页面、65 个带公式 Excel 和 3 份 RFQ Word 模板。

## 打开方式

解压后打开 `index.html`，自动进入询价与报价比对页面。通过网页顶部导航切换九个页面。

## 本次三项修改

1. **所有 9 页的 Word/PDF/Excel/EDI 单据接收模块**：整个模块标题、上传新版和旧版的按钮、两侧文件阅读器、字段定位筛选器默认**全部展开且可见**。从“载入可直接体验的双版本示例”开始到“重新对照、字段提取、字段差异结果”等内容改为**独立折叠区**，默认收起。点击这个折叠区标题可展开操作及详细结果。原有颜色差异与字段定位逻辑保留，上传原件之后依然可以查看两个阅读器。
2. **所有 9 页抬头右上角**：移除文案 `全量演示数据 · 非 GxP 实绩`。没有修改其他地方关于数据真实性、非正式质量批准、样例数据的说明，也没有将演示数据伪装成真实生产记录。
3. **合同核查与条款比对页**：`02 合同字段对比` 的**主对比表仍直接可见**，而从标题 `同一底表的全量计算依据和来源字段（默认前 5 条，点击可展开全部）` 起，到 Excel 下载、全量来源明细以及表内五条/全部行的展开按钮，整体改成**默认收起的独立折叠区**。点击标题后仍可展开原有数据、公式下载。

## 未改动

- 九个业务页面的顺序和业务逻辑、模板内容、核查字段及异常闭环。
- `assets/data.js`、`assets/biz_data.js`、65 个 Excel 工作簿、3 份 Word 模板、原始 CSV。
- 原有可读版本对比、差异红绿标识、字段跳转、人工复核和血缘变量字典。

## 验证与边界

- `node --check assets/app.js` 等 JavaScript 语法检查通过。
- `node qa_v6_behavior.js` 模拟加载九个页面，核验默认展开/折叠层级、合同单独折叠、两侧字段定位和页眉标签移除，9/9 通过。
- 68 个 Excel/Word 文件字节逐一与上一版 ZIP 对比，保持完全一致。
- 当前环境的 Chromium 无法完成可用的端到端页面渲染测试。部署前请在目标 Chrome / Edge 手动核验点击展开、文件上传、双阅读器高亮及 Excel 下载。
- 网页仍是离线 DEMO 原型，实际 PDF/OCR 解析、SAP/ERP、邮件、正式质量审批和电子签名需要后端系统及权限审计。
