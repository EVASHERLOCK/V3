# Pharma Procurement AI — 全站指标计算血缘规则 V2.9.18

## 永久产品规则（与全站 Top10 并列）

> 任何展示给用户的数值，应说明：指标名称/单位、筛选时间范围、参与的记录、数据来源、输入字段、权重或阈值、计算步骤、缺失值/零值规则、计算口径版本和结果复核状态。

**不能将没有来源证据的 DEMO 模拟百分比、情景评分或固定文字描述，宣称为已计算/已实现/已审核的正式业务结果。**

### 三类指标状态

- **已接入可重算公式**：有明确输入，页面能展示来源与计算步骤；可导出真正含 Excel 公式的 `.xlsx` 及全部参与记录。
- **规则/演示情景**：模型能在示例输入上复现；假设率、质量分、供应商风险不得自动当作企业真实指标。
- **血缘待登记**：只能展示模型来源线索或口径缺口；不能用似是而非的解释冒充审计证据。

### 数据粒度约束

- PO 成交价、报价和研发 BOM 必须严格按 Material、币种、数量、日期、批准版本与厂址区分。
- 正式资质只有授权 QA/RA 的受控系统记录能改变；Excel 公式不能批准 GMP/CEP/ASL。
- 如果记录是演示候选，不得归入真实采购金额、真实采购降本、已批准 ASL 或法定证书指标。
- Top 10 展示只影响首屏，导出必须覆盖当前筛选后的**全部参与记录**。
- 业务源数据和计算结果须单独存放；所有可修改假设必须明确为输入，不得隐藏在公式常量中。

### 本版本实现范围

**成本基线与目标成本管理（#/ss-cost）：** 已接入后台生成 `.xlsx`。内含 9 张表：指标摘要、PO输入、报价比较、月度基线、机会假设、供应商差异、成本瀑布、偏差复盘、口径登记簿。所有关键计算使用 Excel 公式单元格（ZIP XML `<f>`），用户可在 Excel 打开后查看或重算。原始 V08 PO 和 RFQ 数据作为 DEMO 输入单独显示。

**全站通用公式入口（26 页）：** 每页统一提供“查看计算依据 / 下载 Excel 公式口径”入口；绝大部分模块和 KPI 旁还有“∑ 公式依据”按钮。其他页面的通用指标目录现支持 PO 总支出、PO 行数、数量加权采购基准、按 PO 的 OTD、延期天数、供应商质量档案平均分等基本公式。**其余业务模块仍未实现完整逐数计算血缘，当前必须显示待补或部分可追溯；这是功能边界，不得宣传为全部完成。**

### 五类降本假设

“替代材料 −6.0%、工艺优化 −3.5%、长期框架 −4.0%、物流优化 −1.8%、付款/汇率 −1.2%”的来源是**未审批演示假设**，并非报价、生产数据或财务认定的历史节省。可下载 Excel 检查 `情景新成本 = 参考成本 × (1 + 降本假设率)`，但验证真实机会时必须补充候选供应商正式报价、质量适用性、切换费用、验证/审计/注册成本与批准责任人。

### 缺失/校验

- Excel 输出由 Node API 生成，不依赖浏览器合成的静态模拟响应；静态托管预览不支持真实 `.xlsx` 接口。
- 源数据当前只包含内置 DEMO，不包含浏览器本地临时导入的文件。未来接入 ERP 或允许用户上传工作簿时，必须将经验证的具体输入版本传入后端并留审计记录。
- 公式单元格不写造假的缓存结果，设置 `fullCalcOnLoad=1`；打开文件需要支持计算的电子表格程序。
- CSV 是纯文本格式，不保存 Excel 公式/跨表引用/数据类型；不允许将 CSV 简单更名成 XLSX。

### 未来逐页覆盖要求

每个原系统模块补全 `指标 key → 字段来源 → 有效口径 → Excel 算式 → 归属页面与筛选 → 复核状态`，同时在 CI 里校验。特别优先：供应商风险率、绩效评分、预算差异、齐套率、CAPA 完成率、Kraljic 分级、OTD/PPV、法规资质覆盖率、ESG、供给风险预测。没有这套证据链就不能宣布“全站每一个数字可审计”。
