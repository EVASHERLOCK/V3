## 强制的“缺失证据”语义

- 当发布快照缺少 BOM 时，不显示推测的企业成本瀑布，明确提示欠缺来源 BOM 行及版本编号；其他四域同理。
- 质量记录 QMS 缺失时不生成质量事件、CAPA 或虚假的零风险结果。
- 五维评分权重直接从每条来源记录读取，且总和必须为 100%。
- 同一快照的分组金额、总金额和 26 页指标 ID 由自动测试验证；快照撤回与哈希链失效均拒绝读数。
- 企业分析快照发布不代表采购下单资格、QA 电子签名、DMF/CEP/GMP 的官方核验或受控 GxP 系统验证。

## 本轮验收技术覆盖

本地 `npm test`、`npm run build`、`npm run check:enterprise:complete`；Node HTTP 的 26 页、未授权拒绝、篡改保护、证据 workbook 下载；隔离 Chromium 的 5 类专用图表与证据展开。由于浏览器安全策略禁止直接访问 localhost，**完整站点浏览器真实 HTTP E2E 尚需在部署环境重做**。

真实 FDA/EDQM 下载仍受当前执行环境 DNS/外网阻碍，真实 ERP/QMS 未提供地址和授权。本轮不能据此宣称生产级全站数据已接通。
