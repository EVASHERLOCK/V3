# V2.9.1 战略寻源与供应商管理 — 导航结构验收

## 本次范围
- 新增一级栏目「战略寻源与供应商管理」，默认常驻展开，不提供折叠二级栏目的控件。
- 新增 9 个独立哈希路由（仅占位页；**尚无业务功能/假数据**）：

| 路由 | 二级栏目名称 |
| --- | --- |
| `#ss-overview` | 战略寻源总览 |
| `#ss-market` | 上游市场调研与供给风险监控 |
| `#ss-kraljic` | Kraljic四象限品类分级与寻源路径 |
| `#ss-ai` | AI供应商智能寻源与评估 |
| `#ss-cost` | 成本基线与目标成本管理 |
| `#ss-project` | 寻源项目全流程管理 |
| `#ss-performance` | 供应商绩效与持续改善管理 |
| `#ss-compliance` | 供应商合规管理 |
| `#ss-technical` | 供应商技术档案与合规资料库 |

- 原 `m03` 供应商情报与寻源、`m04` 供应商质量与准入、`m07` 供应商绩效与风险从用户导航及页面入口移除。旧链接分别重定向到 `#ss-ai`、`#ss-compliance`、`#ss-performance` 占位页。
- 为保护其他页面沿用的数据和报表，旧版共享底层计算代码暂保留（不再作为可访问页面）。
- Overview、01、Top30、02、03、06、08、09、10 与 7 个控制中心均保留。
- V2.9 全站问号分类词典和自动注入保持启用，九个新路由补充了字典默认映射。
