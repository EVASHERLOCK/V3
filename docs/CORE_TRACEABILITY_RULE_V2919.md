# 全站最高优先级规则 — 计算与决策可追溯（V2.9.19）

**适用：全部 26 个页面；所有 KPI、小框、表格、图表、排名、风险、文字建议和报告。**

1. **公式先于结果：** 必须展示指标名称、定义、计量单位、输入字段、数据来源（表/接口/记录 ID）、过滤条件/日期、分子分母、权重比例、完整公式、结果与版本。权重应在图表/列头可见。
2. **文字建议必须可解释：** 展示触发建议的具体数值、比较基准/阈值、适用的业务规则、对应风险或机会以及下一步建议；不可谎称有不可见的“AI 思维链”。当前是确定性规则引擎，文字阐述的是依据和决策规则，不是模型内部隐藏推理过程。
3. **图表不是图片：** 图表必须提供“展开计算/分析”入口及可导出的全量明细。页面默认 Top10 按业务重要度降序展示，剩余折叠；展开或导出不得丢数据。
4. **电子表格可重算：** 涉及计算的页面应提供标准 `.xlsx` 工作簿，使用真实公式单元格、源数据工作表及参数/权重工作表；CSV 不作为公式验收。
5. **来源等级必须清楚：** `V08_DEMO`、`GENERATED_DEMO`、`USER_LOCAL_DEMO`、`OFFICIAL_UNVERIFIED`、`ERP_QMS_VERIFIED` 必须分开；未经验证的官方线索不等于准入、质量或采购批准。缺失不等于 0、失败或已通过。
6. **严禁伪造审批或历史：** 没有项目签核、真实PO、质量事件、审计报告与市场文件时必须标明未知/情景。跨物料候选不得冒充同物料批准来源。
7. **页面放行门禁：** 新 KPI/图表/分析模块若尚无完整计算血缘，必须在页面和全站计算依据面板显示“待登记”；不得在帮助说明中夸称可审计。
8. **交叉模块口径一致：** 同一筛选范围内、同一指标的总量必须可与明细汇总；得分/金额/风险不应不同模块互相矛盾。
9. **GxP/ERP 边界：** 当前是 Non-GxP 演示系统，数据血缘和公式可重算不等于正式合规审计、电子签名、ASL 授权或真实 ERP 下单限制。

## 本轮已覆盖的功能范围
- 成本基线：PO、RFQ、BOM代理基准、机会假设、偏差复盘（V2.9.18）。
- 寻源项目：五项评分权重、每供应商文件登记覆盖、甘特计划时长与来源（V2.9.19）。
- 供应商绩效：研发/量产组合得分、风险评分/等级、OTD×PPV四象限、Spend占比、分层、风险建议阈值（V2.9.19）。
- 其余页面：已接入计算依据 UI，但部分指标仍**待登记**，不能认定完全实现。

## V2.9.22 永久规则补充

所有含数字的KPI、图表、表格都必须携带唯一指标ID、来源版本、业务/币种/时间过滤条件、明确的分子分母/权重、可查看源行、可导出真实公式的Excel。没有登记不能伪造，必须显示MISSING_LINEAGE。

所有文字性建议/风险/根因结论，至少登记独立规则ID、依据指标、阈值、证据行、建议措施与证据缺口。可以披露可核查的决策依据，但不应伪造真实事故因果关系或声称暴露模型内部思维过程。未登记返回UNREGISTERED_ANALYSIS。

所有官方源需要保留官网URL、SHA256、抓取/导入时间、版本与审核人；公开目录数据只构成寻源线索，GMP/CEP/ASL/ERP准入必须在独立受控审核后生效。
