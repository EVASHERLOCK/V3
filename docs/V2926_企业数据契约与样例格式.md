# V2.9.26 企业来源数据契约（Non-GxP 分析）

本文件提供对接结构示意，**不包含任何真实企业数据或密钥**。请先在企业侧完成只读数据映射、源证据核验、币种规范化和业务字段责任签字。Node 端仅将人工核对发布后的数据标记为 `RELEASED_FOR_ANALYTICS_NON_GXP`；这**不是**电子签名、供应商 GMP/CEP 放行、ASL 生效或 PO 下单控制。

### 重要计算与责任规则

- **BOM：** `SUM(qty × target_unit_usd)`、`SUM(qty × quoted_unit_usd)`，差额与比例均可逐行复算。报价仅作相同物料/单位/币种口径比较，不代表已经完成量产成本验证。上游 FX 换算需要留证据。
- **寻源甘特：** 取正式项目阶段 `start_date`、`end_date` 和业务 `status`。阶段标记 DONE 不是 QA 法律意义上的批准签名。
- **五维评分：** 每条原始评分各有五项权重，必须合计 100%；不得使用未经证据验证的“固定权重”覆盖企业提供的评分方法。
- **合规证据：** 仅计算已登记文件中 `review_status=REVIEWED` 且截至查询日期未过期的比例。这**不是**“法定文件覆盖率”或 ASL/GMP 准入资格。
- **报价：** 比较同物料的来源报价单价，MOQ 与运费单列，不将运费不恰当地直接当作单价。企业上线还应加入报价有效期、贸易条款、关税等证据。

### 正式验收最低门槛

1. 运行在持久化受控服务器，使用 `ENTERPRISE_CONNECTOR_PATH` 指向备份和访问控制的持久卷。
2. 通过审批发布快照，确认原始记录数量及快照 SHA-256，测试发布与撤回。
3. 验证 26 个页面使用**同一个快照编号**且逐页对账通过。
4. 同供应商/Site/物料的 BOM、RFQ、项目、文件必须由企业业务负责人对齐主键。
5. 在真实部署服务上运行 `npm run check:enterprise:live`，并将输出与企业 ERP/QMS 的原始报表人工核对。
6. FDA/EDQM 等官方数据源单独运行 `npm run check:integrations`；**不能**用 ERP/QMS 内部接口验收代替官方联网验收。

### 关键接口及访问权限

- `GET /api/enterprise/evidence/schema`：五类数据结构和 20 项专用指标，管理员权限。
- `GET /api/enterprise/dashboard?route=ss-cost`：按页面读取同一审核快照，不提供 DEMO 回退，管理员权限。
- `GET /api/enterprise/reconciliation`：26 页对账汇总，管理员权限。
- `GET /api/enterprise/evidence/workbook.xlsx`：源行、专用模型及 Excel 计算公式，管理员权限；快照完整性校验不通过会拒绝下载。
- `GET /api/integrations/enterprise/status`：受控企业快照状态摘要；具体可见性由部署策略和服务器权限管理决定。
